# NES controller photograph

`nes-controller-flat.jpg` is the unmodified original photograph by Evan-Amos,
dated 2014-09-02 and released into the public domain by its author.

- Source: https://commons.wikimedia.org/wiki/File:NES-Controller-Flat.jpg
- File: https://upload.wikimedia.org/wikipedia/commons/e/e2/NES-Controller-Flat.jpg

- Dimensions: 3721 × 1870
- SHA-256: `0ac5f45fe5180e2e914dbfe2ec38e374d38c998f5c9e1b2337bec65daf40d21e`

`ControllerManual.astro` places HTML keyboard controls over measured positions
in this image. Astro generates local 640px and 1280px WebP variants at build
time; the photograph is not fetched from Wikimedia at runtime. The controller's
printed labels and Nintendo mark remain part of the original photograph.
