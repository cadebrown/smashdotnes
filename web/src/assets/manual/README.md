# Manual material

`battered-paper.png` is a generated decorative paper texture, created with the
built-in image-generation tool on 2026-09-08. It depicts stained paper, toner
smears, creases, adhesive residue, and worn edges. It is not a historical scan.

The brief requested a flat, square, full-bleed background for an aggressively
worn game manual, with heavy damage at the edges and a pale central area for
readable instructions. No text, logos, game hardware, or game screenshots were
generated. The original result is retained here; Astro builds an optimized
1200px WebP and exposes its URL through `--manual-paper` in ControllerManual.

The real Nintendo controller photograph remains in `../controllers/`, with its
own attribution. Game captures and fighter sprites remain original game assets.
