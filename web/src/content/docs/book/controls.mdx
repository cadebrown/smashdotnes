In battle, **A / D** moves, **W** jumps, **J** jabs, and **K** uses your special. Release **W** and press it again in the air for the second jump.

<JumpSequence />

At the title, **W / S** chooses an option and **Enter** or **J** confirms. In the lobby, **A / D** selects P1; **W / S** selects the other fighter in CPU modes. **Enter + '** returns to the title during battle.

<details>
<summary>Why did held J stop after one jab?</summary>

Each press accepts one action. Release J before pressing it again.

</details>

On touch, **Up** jumps, **A** jabs, and **B** uses a special. Click or tap the game before playing; controls release when it or the browser loses focus. The keyboard map is P1 only.
