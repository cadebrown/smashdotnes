### Find the distance

<AnnotatedScreenshot scene="jab" />

Get inside an attack’s reach before committing. A jab can miss when you are too far away; a special can cover more space.

### Build damage

<AnnotatedScreenshot scene="hit" />

Hits add percentage and knock fighters sideways. More percentage means farther knockback, so push an opponent toward an edge while protecting your own position.

### Recover

Walk off an edge, turn inward, and tap **W** while falling. Release it and tap again only if you need the second jump. The platform catches you while you fall onto it; there is no ledge grab. Crossing a side or bottom boundary respawns you at zero percent.

For the exact rules, see [physics](/docs/physics/) and [contact](/docs/contact/).
